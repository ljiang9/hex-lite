# hex-lite

极简 Hex 连接棋：红（先手）把上下两条边连起来，蓝把左右两条边连起来。
Hex 定理保证满盘必有一方获胜——这个游戏没有和棋。

纯 Python 标准库，无第三方依赖。

## 玩法

- 棋盘是菱形六角格（默认 7×7，可 `--size 11` 用标准尺寸）
- 红 `●` 连**上下**边，蓝 `○` 连**左右**边
- 人机对战：你执红先手，AI 执蓝；输入如 `3 4` 落子，`q` 退出

## 用法

```bash
python3 -m hex_lite                  # 人机对战
python3 -m hex_lite --auto           # AI 对 AI 自动演示（10 局）
python3 -m hex_lite --auto --games 20 --seed 7 --size 11
python3 -m hex_lite --auto --verbose # 打印每步棋盘
```

## AI 说明

1 步前瞻 + 虚连接距离（Dijkstra：己方子代价 0、空格代价 1、敌子不可走）。
每步优先走即时胜，否则最大化「对手虚连接距离 − 己方虚连接距离」。
这不是精确求解（Hex 的完整博弈树极大），只是贪心启发式。

## 诚实局限

- AI 只是 1 步贪心启发式，不做深层搜索；熟悉定式的人类通常能赢
- 未实现 pie rule（换手规则），先手优势未被平衡
- 文本棋盘，无图形界面/存档/悔棋；Python 3.10+
